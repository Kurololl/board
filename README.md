# Board

Доска с рисованием, заметками, картинками и папками. Всё хранится прямо в вашем
GitHub-репозитории в виде файлов. Внешних сервисов и баз нет.

## Как устроено хранение

- Сайт (`index.html`, `style.css`, `app.js`) лежит в ветке `main` и раздаётся через GitHub Pages.
- Данные лежат в отдельной ветке `board-data`, которую сайт создаёт сам при первом сохранении:
  - `boards/main.json`: главная доска;
  - `boards/<id>.json`: содержимое каждой папки, у каждой папки свой файл;
  - `images/<id>.webp`: загруженные картинки.
- Каждое сохранение — это коммит. Вся история изменений видна в репозитории.
- Данные лежат в отдельной ветке, чтобы сохранения не пересобирали сайт на Pages каждый раз.

## Установка

1. Создайте **публичный** репозиторий и загрузите в него `index.html`, `style.css`, `app.js`.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Создайте токен: **GitHub → Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token**:
   - Repository access: **Only select repositories** → этот репозиторий;
   - Permissions → Repository permissions → **Contents: Read and write**.
4. Откройте сайт `https://<логин>.github.io/<репозиторий>/` → ⚙️ → вставьте токен → Save.
   Owner и Repository подставятся сами.

Токен хранится только в вашем браузере. **Не коммитьте его в репозиторий.**

## Совместная работа

- Каждому, кто редактирует, нужен свой токен. Добавьте человека в коллабораторы
  (Settings → Collaborators), и он создаст токен со своего аккаунта.
- Без токена доска открывается только для просмотра.
- Изменения сохраняются автоматически через ~2.5 с после правки (или сразу по `Ctrl+S`).
- Изменения других людей подтягиваются раз в 15 с. Если двое правили одновременно,
  изменения сливаются: каждый объект берётся из той версии, где его меняли.

## Папки

- 📁 или `F` создаёт папку. Название можно вписать прямо на карточке.
- Двойной клик по папке или кнопка **Open →** открывает её, это отдельная доска внутри.
- Перетащите заметку, картинку или другую папку на папку, и она переедет внутрь.
- Сверху показан путь «🏠 Home › Идеи › Референсы», по нему можно кликать.
  `Esc` поднимает на уровень выше.
- Ссылка 🔗 ведёт прямо в текущую папку.

## Управление

| Действие | Как |
|---|---|
| Двигать доску | ✋ + тянуть, пробел + тянуть, средняя кнопка мыши, два пальца |
| Зум | колесо мыши / щипок |
| Карандаш / ластик / выбор | `P` / `E` / `V` |
| Заметка | `N`, 📝 или двойной клик по пустому месту |
| Папка | `F` или 📁 |
| Картинка | `I`, 🖼️, перетащить файл, `Ctrl+V` |
| Отмена | `Ctrl+Z` |
| Сохранить сейчас | `Ctrl+S` |
| Выйти из папки | `Esc` |

## Ограничения

- Изменения видны другим не мгновенно, а с задержкой до ~15 с.
- Если удалить папку или картинку, файлы остаются в репозитории. Это и есть ваша история.
- Без настроенного GitHub (например, при запуске через `python -m http.server`) доска
  работает в режиме **Local only** и хранит всё в браузере. Это удобно для проверки.
