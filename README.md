# Board

Совместная доска: рисование, заметки, картинки, курсоры других людей в реальном времени.
Хостинг — GitHub Pages, бэкенд — Supabase (бесплатный план).

## 1. Проверка без настройки

Залейте файлы на GitHub Pages (шаг 3) или запустите локально:

```
python -m http.server 8000
```

и откройте `http://localhost:8000`. Без ключей Supabase доска работает в **Local mode**:
всё хранится в браузере, вкладки синхронизируются между собой.

## 2. Supabase

1. Зарегистрируйтесь на supabase.com → **New project** (регион поближе, например Frankfurt).
2. **SQL Editor** → вставьте содержимое `schema.sql` → **Run**.
   Это создаст таблицы, включит realtime и bucket `images` для картинок.
3. **Project Settings → API**: скопируйте **Project URL** и **anon / publishable key**.
4. В `app.js` первые две строки:

```js
const SUPABASE_URL = "https://xxxx.supabase.co";
const SUPABASE_KEY = "ваш anon/publishable ключ";
```

Ключ публичный, его можно коммитить. Никогда не вставляйте сюда `service_role` / secret key.

## 3. GitHub Pages

1. Новый репозиторий → загрузите `index.html`, `style.css`, `app.js`.
2. **Settings → Pages → Source: Deploy from a branch → main / root** → Save.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

## Управление

| Действие | Как |
|---|---|
| Двигать доску | инструмент ✋ + тянуть, пробел + тянуть, средняя кнопка мыши, два пальца |
| Зум | колесо мыши / щипок |
| Карандаш / ластик / выбор | `P` / `E` / `V` |
| Заметка | `N`, кнопка 📝 или двойной клик по пустому месту |
| Картинка | `I`, кнопка 🖼️, перетащить файл, или `Ctrl+V` |
| Ссылка на картинку | `Ctrl+V` URL картинки — пин без загрузки |
| Текст из буфера | `Ctrl+V` — создаст заметку |
| Отмена | `Ctrl+Z` |
| Пропорции картинки при ресайзе | держите `Shift`, чтобы менять свободно |

Каждая доска — своя ссылка вида `...#b=abc123`. Кнопка 🔗 копирует ссылку, ＋ создаёт новую доску.

## Важно

- Доступ по принципу «у кого ссылка — тот редактирует». ID доски случайный, угадать его сложно,
  но защиты паролем нет.
- Бесплатный проект Supabase засыпает после недели без активности — разбудить можно в дашборде.
- Картинки сжимаются в WebP до 1600 px перед загрузкой, чтобы 1 ГБ хранилища хватало надолго.
- Если курсоры не видны, а данные синхронизируются: **Project Settings → Realtime** →
  убедитесь, что не включён режим «только приватные каналы».
