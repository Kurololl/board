# Board

Доска с рисованием, заметками, картинками, папками и нитями-связями.

Есть три режима хранения. Сайт выбирает режим сам:

| Режим | Когда включается | Что даёт |
|---|---|---|
| **Live (Supabase)** | в `app.js` вписаны `SUPABASE_URL` и `SUPABASE_KEY` | изменения у всех за ~0.5 с, курсоры других людей, токены не нужны |
| **GitHub** | ключей Supabase нет, сайт открыт на `github.io` | данные лежат файлами в репозитории, у каждого редактора свой токен |
| **Local only** | ни то ни другое | всё хранится в браузере, удобно для проверки |

## Режим Live (рекомендуется для совместной работы)

1. Зарегистрируйтесь на supabase.com → **New project** (регион поближе, например Frankfurt).
2. **SQL Editor** → вставьте содержимое `schema.sql` → **Run**.
3. **Project Settings → API**: скопируйте **Project URL** и **anon / publishable key**.
4. Вставьте их в первые две строки `app.js`:

```js
const SUPABASE_URL = "https://xxxx.supabase.co";
const SUPABASE_KEY = "ваш anon/publishable ключ";
```

5. Залейте `index.html`, `style.css`, `app.js` в репозиторий с включённым Pages.

Ключ публичный, его можно коммитить. Никогда не вставляйте сюда `service_role` / secret key.

**Важно:** в этом режиме редактировать может любой, у кого есть ссылка на сайт.
Бесплатный проект Supabase засыпает после недели без активности, разбудить его можно в дашборде.

В правом верхнем углу можно вписать своё имя: его увидят другие рядом с вашим курсором.

## Режим GitHub

Данные лежат в ветке `board-data`: `boards/*.json` (доски и папки) и `images/` (картинки).
Каждое сохранение — коммит. Для этого режима репозиторий должен быть публичным.

### Как получить токен (даже если вы создатель репозитория)

GitHub не выдаёт токен автоматически. Его нужно создать, и показывается он только один раз.

1. github.com → аватар справа вверху → **Settings**.
2. В самом низу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens**.
3. **Generate new token**:
   - Token name: любое, например `board`;
   - Expiration: срок действия (можно до года);
   - Repository access: **Only select repositories** → ваш репозиторий с доской;
   - Permissions → **Contents** → **Read and write**.
4. **Generate token** → сразу скопируйте `github_pat_…`. Потом его уже не показать.
5. Откройте сайт → ⚙️ → вставьте токен → **Save**.

Если токен потерялся или истёк, создайте новый тем же способом. Старый можно удалить там же.
Не коммитьте токен в репозиторий: GitHub его обнаружит и отзовёт.

## Оформление и связи

- Кликните по заметке, папке или картинке, и над ней появится панель:
  цвет фона, размер текста **A− / A+**, жирный **B** (`Ctrl+B`), цвет текста **A**,
  🧵 связать с другим пином, 🗑️ удалить.
- Нити-связи можно провести двумя способами: инструментом 🧵 (`C`), протянув от пина к пину,
  или кнопкой 🧵 на панели пина и кликом по второму пину.
- Клик по нити выделяет её: можно сменить цвет или удалить (`Del`).

## Папки

- 📁 или `F` создаёт папку, название вписывается прямо на карточке.
- Двойной клик или **Open →** открывает её как отдельную доску.
- Перетащите пин на папку, и он переедет внутрь.
- Сверху показан путь «🏠 Home › …», `Esc` поднимает на уровень выше.

## Управление

| Действие | Как |
|---|---|
| Двигать доску | ✋ + тянуть, пробел + тянуть, средняя кнопка мыши, два пальца |
| Зум | колесо мыши / щипок |
| Карандаш / ластик / выбор | `P` / `E` / `V` |
| Заметка | `N`, 📝 или двойной клик по пустому месту |
| Папка | `F` или 📁 |
| Картинка | `I`, 🖼️, перетащить файл, `Ctrl+V` |
| Связать пины | `C` и протянуть от пина к пину |
| Удалить выделенное | `Delete` / `Backspace` |
| Снять выделение / выйти из папки | `Esc` |
| Отмена | `Ctrl+Z` |
| Сохранить сейчас | `Ctrl+S` |
